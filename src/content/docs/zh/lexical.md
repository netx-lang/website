# 词法结构

NetX 语言的词法元素如下：

- 空白字符
- 符号
- 注释
- 标识符和关键字
- 字面量

本节使用 ANTLR 正则表达式表示法来定义 NetX 语言的词法元素。
具体来说，我们使用以下表示法：

- `''` 包围字符串字面量。例如，`'hello world'` 是与字符串 `hello world` 完全匹配的正则表达式。
- `.` 运算符匹配任意单个字符。
- `~` 运算符匹配除其后集合中的字符之外的任意字符。
  例如，表达式 `~('\n')` 匹配除换行符之外的任意字符。
- `|` 表示正则表达式匹配运算符左侧或右侧的内容。
  例如，表达式 `'true' | 'false'` 匹配字符串 `'true'` 或 `'false'`。
- 此外，我们使用 `[]` 包围字符集合。该表达式匹配集合中的任意单个字符，例如 `[01]` 匹配字符 `0` 或 `1`，而 `[a-zA-Z]` 匹配英文字母中的任意小写或大写字母。
- `*` 运算符匹配前置元素出现零次或多次。
  例如，表达式 `[1-9][0-9]*` 匹配任意正整数，该整数以 1 到 9 的数字开头，后面跟随零个或多个 0 到 9 的数字。
- `+` 运算符匹配前置元素出现一次或多次。
  例如，表达式 `[01]+` 匹配任意二进制数，该数由一个或多个 `0` 或 `1` 组成。
- `?` 运算符匹配前置元素出现零次或一次。
  例如，表达式 `[0-9]?` 匹配 0 到 9 中的单个数字，或什么都不匹配。
- 正则表达式后的 `-> skip` 指令表示应忽略匹配的文本，即由词法分析器跳过该文本。

## 空白字符

空白字符用于分隔源代码中的标记。它们包括空格、制表符和换行符。编译器通常会忽略空白字符，除非它们对于分隔标记是必要的。

```antlr
WHITE_SPACE: [ \t\r\n]+ -> skip;
```

## 注释

注释用于注释代码，编译器会忽略它们。注释可以是单行注释（以 `//` 开头），也可以是多行注释（由 `/* ... */` 包围）。

```antlr
COMMENT: '//' ~('\n')* '\n' -> skip;
BLOCK_COMMENT: '/*' .*? '*/' -> skip;
```

## 字面量

字面量是直接写在代码中的固定值。它们包括布尔字面量、浮点数字面量，以及具有不同宽度（二进制表示的位宽）和基数的数值字面量。

- 布尔值：布尔字面量为 `true` 和 `false`。
- 浮点数：浮点数字面量可以指定宽度。
  支持的宽度为 16、32 和 64 位，分别对应半精度、单精度和双精度 IEEE 754 格式。
  例如：`32'f3.14` 是表示值 3.14 的单精度浮点数字面量。
  如果未指定宽度，编译器应将其视为 32 位单精度浮点数。
- 数值：数值字面量可以指定宽度和基数。
  基数可以是 `b`（二进制）、`h`（十六进制）、`o`（八进制）或 `d`（十进制）。
  指定的值是采用指定基数的一系列数字。宽度为正整数，值中可以包含下划线以提高可读性。
  例如：`4'b1010` 是表示 4 位数字的二进制字面量，其二进制值为 `1010`。
  对于未指定宽度和基数的字面量，编译器应将其视为 32 位十进制数。

```antlr
BOOLEAN : 'true' | 'false';
BIN_NUMBER : INTEGER '\'' [bB] [01] [01_]*;
HEX_NUMBER : INTEGER '\'' [hH] [0-9a-fA-F] [0-9a-fA-F_]*;
OCT_NUMBER : INTEGER '\'' [oO] [0-7] [0-7_]*;
DEC_NUMBER : INTEGER '\'' [dD] [0-9] [0-9_]*;
INTEGER : [0-9] [0-9_]*;
FLOAT : INTEGER ('.' INTEGER)?;
SIZED_FLOAT : INTEGER '\'' [fF] FLOAT;
```

例如，以下字面量是有效的：

```netx
true, false, 4'b1010, 8'hFF, 12'o17, 32'd42, 3.14, 64'F2.71828
```

请注意，给定的宽度可能与数字序列不匹配，在这种情况下，编译器会在字面量前补充前导零，或截断字面量以适应指定的宽度。

## 字符串

字符串是由双引号包围的字符序列。它们仅用于系统函数 `print`。

```antlr
STRING : '"' (~["\\] | '\\' .)* '"';
```

## 符号

符号包括 NetX 语言语法中使用的运算符、分隔字符和括号。
它们可分为以下几类：

- **电路组装**：`<>`（串行组合子）、`||`（并行组合子）、`#`（端口修饰符）
- **算术**：`+`（加）、`-`（减）、`*`（乘）、`/`（除）、`%`（取模）、`**`（乘方）
- **比较**：`<`、`<=`、`>`、`>=`、`==`、`!=`，以及无符号变体 `<*`、`<=*`、`>*`、`>=*`
- **位运算**：`&`（与）、`|`（或）、`^`（异或）、`~`（非）、`^~` 与 `~^`（同或）
- **移位**：`>>`（右移）、`<<`（左移）、`>>>`（算术右移）、`<<<`（算术左移）
- **列表与范围**：`++`（列表连接）、`..`（范围）
- **分隔符与绑定**：`=`（绑定）、`,`（分隔）、`->`（端口箭头）、`;`（终止符）、`:`（注解）、`.`（字段访问），以及括号 `( )`、`[ ]`、`{ }`

完整的优先级顺序见运算符优先级与结合性一节。
注意，上面的列表不包括逻辑运算符，因为它们在 NetX 语言中写作关键字 `and`、`or` 和 `not`。

## 标识符和关键字

标识符是代码中用于标识组件、数据和其他实体的名称。
它们必须以字母或下划线开头，后面可以跟随字母、数字或下划线。

```antlr
ID : [a-zA-Z_] [a-zA-Z0-9_]*;
```

标识符不能与任何保留关键字相同。保留关键字是在 NetX 语言中具有预定义含义的特殊字符串。
保留关键字按用途分组如下：

- **声明与导入**：`application`、`library`、`import`、`as`、`component`、`interface`、`enum`
- **数据**：`default`、`wire`、`bundle`、`auto`、`of`
- **元编程**：`let`、`for`、`if`、`then`、`else`、`in`、`when`
- **字面量与逻辑**：`true`、`false`、`and`、`or`、`not`
