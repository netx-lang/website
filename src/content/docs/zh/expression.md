# 表达式

NetX 中的表达式用于构建和操作硬件设计，以及执行元编程计算。
每个表达式都有一个类型，该类型由其操作数和使用上下文决定。
本节将介绍 NetX 中各种表达式的语法和语义，包括电路表达式、列表表达式等。

## 电路表达式

电路表达式用于在 NetX 中描述硬件设计。
它们可用于实例化组件、连接导线，以及对电路元素执行各种操作。

### 电路常量

电路常量是参与电路表达式的常量，此时常量字面量会被解释为一个特殊组件，该组件没有输入，只有一个输出端口，输出值为该常量值。
这也包括在 NetX 编译期计算中求值为常量的常量表达式。

例如，在以下表达式中

```netx
immU <> CONCAT <> (instr[31:12] || 12'b0)
```

`12'b0` 是一个电路常量，表示一个类型为 $\langle \rangle \to \langle \mathrm{bit}(12)\rangle$ 的组件，持续输出 `12'b0`。
将 `12'b0` 替换为求值结果为 `12'b0` 的元表达式，例如 `12'd42 ^ 12'd42`，不会改变该电路表达式的语义。

### 内置组件

内置组件是全局作用域一节中列出的组件，可在全局作用域中使用。
这些组件可以直接用于电路表达式，无需额外的导入语句，从而让你能够实例化逻辑门、寄存器和其他基本电路元素。
在大多数情况下，这些组件的输入和输出信号类型由上下文推断，不过有些组件具有显式指定其输入和输出类型的属性。

- `DUP` 将一个输入信号复制到多个输出。
  它具有一个属性 `n`，用于指定输出数量。
  例如，以下代码将常量值 `12'b0` 传递给两条导线 `a` 和 `b`，每条导线都承载一个 `bit(12)` 信号：
  
```netx
wire a, b of bit(12);
(a || b) <> DUP(2) <> 12'b0
```

- `TO` 是一条匿名导线，将其输入原样传递到输出。它等价于 `DUP(1)`，但没有任何属性。
- `CONCAT` 将多个输入信号拼接为一个输出信号。
  它可以接受一个属性 `n`，用于指定输入数量；如果省略，编译器将根据上下文推断输入数量。
  例如，以下代码表明，导线 `a` 承载的信号由常量 `1'b1`、导线 `b` 的信号和常量 `5'b0` 拼接而成：
  
```netx
wire a of bit(20);
wire b of bit(14);
a <> CONCAT <> [1'b1, b, 5'b0];
```

- `SPLIT` 将一个信号拆分为多个输出。
  它具有一个属性 `n`，用于指定输出数量。
  它接收一个 n 位输入信号，并产生 n 个 1 位输出。
  例如，以下代码
  
```netx
wire a, b of bit(1);
wire c    of bit(2);
[a, b] <> SPLIT(2) <> 2'b10;
```

  等价于
  
```netx
wire a, b of bit(1);
wire c    of bit(2);
[a, b] <> [c[1], c[0]];
```

- `CAST` 和 `UCAST` 用于将信号从一种类型转换为另一种类型。
  它们具有一个属性 `width`，用于指定输出信号的目标位宽；如果未指定，编译器将根据上下文推断。
  如果输入信号的位宽大于目标位宽，组件会截断输入以适配目标位宽。
  如果输入信号的位宽较小，则会扩展信号：`CAST` 使用信号的最高有效位进行符号扩展，而 `UCAST` 进行零扩展，使其与目标位宽匹配。
- `REGISTER` 创建一个寄存器，用于存储一个值，并在时钟信号的边沿更新该值。
  它具有一个属性，用于指定寄存器是在时钟的上升沿还是下降沿更新。
  第一个输入是时钟信号，第二个输入是要存储的值。
  唯一的输出是所存储的值。
  用法如下：
  
```netx
wire input, output of bit(32);
wire clk of clock();
output <> REGISTER(pos_edge = true) <> [clk, input]
```

  也可以简写为 `output <> REGISTER(true) <> [input, clk]`。
- `ASYNC_REGISTER` 创建一个寄存器，根据复位信号异步复位其值。
  它具有三个属性：`pos_edge`、`high_rst` 和 `rst_value`，分别指定
  (1) 寄存器是在时钟的上升沿还是下降沿更新；
  (2) 寄存器是在复位信号为高电平还是低电平时复位；以及
  (3) 复位信号有效时寄存器复位到的值。
  它有三个输入：时钟信号 `clk`、复位信号 `rst` 和输入 `i`。
  用法如下
  
```netx
wire input, output of bit(32);
wire rst           of bit(1);
wire clk           of clock();
output <> ASYNC_REGISTER(
  pos_edge = true, 
  high_rst = true, 
  rst_value = 0
) <> [clk, rst, input];
```

- `NOT` 是一个一元组件，对其输入信号取反。
  它没有属性，产生一个输出信号，其值为输入的逻辑非。
- `AND`、`OR`、`XOR`、`XNOR`、`NAND` 和 `NOR` 是对输入信号执行逻辑运算的组件。
  它们具有一个属性 `n`，用于指定输入数量；如果省略，编译器将根据上下文推断输入数量。
- `EQ`、`NE`、`SLT`、`SLE`、`SGT`、`SGE`、`ULT`、`ULE`、`UGT` 和 `UGE` 是对两个输入信号执行比较运算的组件。
  它们没有属性，产生一个 1 位宽的输出信号，用于表示比较结果。
  前缀 `S` 表示有符号比较，而 `U` 表示无符号比较。
- `SHL`、`LSHR`、`ASHR` 是对两个输入信号执行移位运算的组件。
  `SHL` 执行逻辑左移，`LSHR` 执行逻辑右移，`ASHR` 执行算术右移。
  它们没有属性，产生一个与第一个输入位宽相同的输出信号。
- `ADD`、`SUB`、`MUL`、`DIV` 和 `MOD` 是对输入信号执行算术运算的组件。
  其中，`ADD` 和 `MUL` 具有一个指定输入数量的属性；如果省略，编译器将根据上下文推断输入数量；其余组件仅对两个输入进行运算，且没有属性。

### 导线与导线位选

导线是特殊的 1 输入 1 输出组件，将其输入原样直接传递到输出。
它们可用于连接电路的不同部分，或在组件之间传递信号。

- 导线可用于表示电路中的环路。
  例如，以下代码创建了一条名为 `counter` 的导线，它从寄存器接收输入，并将其反馈给该寄存器，从而形成一个环路，在每个时钟周期递增计数器的值：
  
```netx
wire counter of bit(32);
wire clk of clock();
counter <> REGISTER(pos_edge = true) <> [
  ADD <> [counter, 1], clk
];
```

  请注意，NetX 不允许组合逻辑环路，即不包含任何寄存器来打断路径的环路。例如，以下代码将被拒绝：
  
```netx
wire a of bit(1);
a <> ADD <> [a, 1]; // ERROR: Combinational loop
```

- 电路中的每条导线必须恰好有一个信号源驱动其输入；这称为禁止多驱动规则。
  具体来说，一旦一条导线被用作组件的输入，其输入端口就被视为已占用，不能再连接到任何其他组件。
  例如，以下代码将被拒绝：
  
```netx
component TEST : [a] -> [b] {
  wire a, b of bit(32);
  [b, b] <> [42, 0];  // ERROR: Multiple drivers for wire b
  a <> ADD <> [b, 1]; // ERROR: Using the occupied input port of wire a
}
```

- 可以通过索引访问导线中的各个位，这称为位选。
  例如，对于声明为 `wire a of bit(2)` 的 2 位宽导线，表达式 `a[1] || a[0]` 等价于直接写 `a`。
  此外，还可以通过切片对导线中的一段位范围进行位选。
  例如，对于声明为 `wire a of bit(4)` 的 4 位宽导线，表达式 `CONCAT <> [a[3], a[2], a[1]]` 等价于切片 `a[3:1]`。
  位选索引必须是常量表达式，超出范围的索引会被编译器拒绝。
- 导线也可以组织为数组，即通过常量表达式索引的导线集合。
  例如，`wire arr[4] of bit(8)` 声明了一个名为 `arr` 的数组，包含四条导线，每条导线宽 8 位。
  需要注意的是，由 n 条 1 位导线组成的数组与一条 n 位导线不同：
  一条 n 位导线承载一个 n 位信号，可以作为整体参与运算（例如按位运算或算术运算），从而为编译器提供更多优化机会。
  相比之下，由 n 条 1 位导线组成的数组包含 n 条独立导线，每条导线承载一个 1 位信号，它们被视为独立的实体。
  可以使用常量索引访问数组元素，例如，`arr[2]` 表示数组中的第三条导线。
  但是，数组不支持切片（选择一段元素范围）。

### 线束与字段访问

线束是将多条导线组合在一起的复合类型，便于访问和操作相关信号（我们已在电路类型一节中讨论过线束类型）。
可以使用点记法访问线束中的每个字段（如果线束是嵌套的，可以连续使用点记法）。

例如，考虑以下代码：

```netx
interface PACKAGE : [valid, load]{
  wire valid of bit(1);
  wire load of bit(32);
}
```

```netx
component TEST : [a, b] -> [c] {
  wire a, b, c of PACKAGE;
  c <> PACKAGE <> [
    AND <> [a.valid, b.valid],
    ADD <> [a.load, b.load]
  ];
}
```

这等价于：

```netx
component TEST : [a, b] -> [c] {
  wire a, b, c of PACKAGE;
  c.valid <> AND <> [a.valid, b.valid];
  c.load  <> ADD <> [a.load, b.load];
}
```

由于串行组合支持命名连接（参见组合子表达式一节），因此它也等价于：

```netx
component TEST : [a, b] -> [c] {
  wire a, b, c of PACKAGE;
  c <> PACKAGE <> {
    valid : AND <> [a.valid, b.valid],
    load  : ADD <> [a.load, b.load]
  };
}
```

### 组合子表达式

组合子表达式用于组合电路中的组件和导线。
通过组合较简单的组件和导线，可以创建复杂电路。
组合子表达式是由连接在一起的一系列组件和导线构成的，其中每个组件都可以有多个输入和输出。
组件的连接方式允许一个组件的输出用作另一个组件的输入，从而形成组件图。

#### 并行组合子

并行组合子 `||` 用于并行组合组件，使它们能够独立且同时运行。
例如，将两个 2 输入 1 输出组件并行组合，会得到一个 4 输入 2 输出组件。
给定一个类型为 $\langle \mathrm{bit}(1), \mathrm{bit}(1)\rangle \to \langle \mathrm{bit}(1)\rangle$ 的组件 `AND`，并行组合 `AND || AND` 会得到一个类型为 $\langle \mathrm{bit}(1), \mathrm{bit}(1), \mathrm{bit}(1), \mathrm{bit}(1)\rangle \to \langle \mathrm{bit}(1), \mathrm{bit}(1)\rangle$ 的组件。

由于硬件并行运行，像 `(e1 || e2 || e3 || e4)` 这样的长并行链很常见。
为了简化此类表达式，NetX 提供了列表记法：`[e1, e2, e3, e4]` 是并行组合子链的语法糖。虽然对于较短的表达式，列表记法看起来差别不大，但当它与高级列表表达式（例如列表推导式）结合使用时，就会变得特别强大，使构建大型并行组合更加方便。
例如，

```netx
wire a of bit(8);
 OR <> (a[0] || a[2] || a[4] || a[6]);
AND <> (a[1] || a[3] || a[5] || a[7]);
```

等价于：

```netx
wire a of bit(8);
 OR <> [a[i] | i in [0..8], when i % 2 == 0];
AND <> [a[i] | i in [0..8], when i % 2 == 1];
```

#### 串行组合子

串行组合子 `<>` 将组件串联起来，把一个组件的输出直接作为下一个组件的输入，类似于函数复合。

例如，可以使用 `NOT <> AND` 将一个 `AND` 门连接到一个 `NOT` 门。这种组合的行为与 `NAND` 门相同，因为 `AND` 的输出会立即被 `NOT` 取反。
还可以通过串联组件构建更复杂的电路。例如，`AND <> (AND || AND)` 先并行组合两对输入（使用 `AND || AND`），再将它们的输出串行送入另一个 `AND` 门，从而创建一个 4 输入 1 输出的与门。

串行组合子要求第二个操作数的输出类型与第一个操作数的输入类型匹配。具体来说，端口数量和每个对应端口的位宽必须完全相同，组合才有效。

当硬件组件具有许多输入和输出端口时，串行组合子支持使用命名连接来简化复杂布线，并使其更加清晰。

例如，考虑以下代码：

```netx
component CHIP : [clk, rst, en, input_a, input_b] -> [output_a, output_b] {
  /* ... */
}

component TOP {
  wire my_clk of clock();
  wire my_rst, my_en of bit(1);
  wire x, y, out_a, out_b of bit(32);
  [out_a, out_b] <> CHIP <> [my_clk, my_rst, my_en, AND <> [x, y], OR <> [x, y]];
}
```

可以使用命名连接将其改写得更加清晰：

```netx
{
  output_a : out_a,
  output_b : out_b
} <> CHIP <> {
  clk     : my_clk,
  rst     : my_rst,
  en      : my_en,
  input_a : AND <> [x, y], 
  input_b : OR <> [x, y]
}
```

这里，`:` 运算符将组件的每个端口与电路中的特定导线或表达式显式关联，而不受它们在端口列表中顺序的影响。
这种方式提高了可读性和可维护性，尤其适用于具有许多端口的组件。
请注意，命名连接可以包含一种特殊形式 `default : expr`，表示对于未指定的端口，将使用表达式 `expr` 作为默认连接。
命名连接可用于输入端口、输出端口或两者。如果某一侧未使用命名连接，仍可根据需要在该侧使用按位置（未命名）连接。

### 装饰器表达式

装饰器表达式使用端口装饰器 `#` 来忽略组件的输入或输出端口。
当你希望选择性地忽略组件的某些输入或输出端口时，装饰器表达式很有用，它让你只需关注与当前连接相关的端口。当组件具有多个端口，而你只需要连接其中一部分时，这尤其有帮助。

例如，考虑以下代码片段，它使用一个 1 位全加器组件定义了一个 32 位超前进位加法器：

```netx
component FULL_ADDER : [a, b, cin] -> [sum, cout] {
  wire a, b, cin, sum, cout of bit(1);
  /* ... */
}
```

```netx
component ADDER : [a, b] -> [c] {
  wire a, b, c of bit(32);

  let bit_adder(i) = [#c[i], TO] <> FULL_ADDER <> [a[i]#, b[i]#, TO];
  let adder(i) = bit_adder(i) <> (
    if i == 0 then 1'b0 
    else adder(i - 1)
  );
  adder(31);
}
```

在这个示例中，`FULL_ADDER` 组件有三个输入端口（`a`、`b`、`cin`）和两个输出端口（`sum`、`cout`）。
在构建 32 位加法器时，每一级只需要连接特定端口。端口装饰器 `#` 用于忽略某次连接中不需要的端口。
例如，`a[i]#` 和 `b[i]#` 表示只使用这些导线的输出，而 `#c[i]` 表示只关注 `c[i]` 的输入。
`TO` 组件用于直通未被忽略的端口。
在这个例子中，我们得到 `bit_adder(i)`，它是一个 1 输入 1 输出组件，接收进位输入信号并产生进位输出信号；通过递归宏 `adder(i)` 将它们串行连接起来，就构建出了一个 32 位加法器。

使用装饰器表达式，可以为复杂电路编写简洁易读的代码，避免不必要的布线，并明确每个连接的意图。这种方式在递归或参数化电路定义中尤其强大，因为在这些定义中，你希望在每一步都有条理地只连接相关端口。

## 列表表达式

NetX 中的列表表达式既是并行组合子（参见组合子表达式一节）的强大语法糖，也是对元编程很有用的数据结构。

### 列表字面量

列表字面量用方括号括起来，元素之间用逗号分隔。例如，`[1, 2, 3]` 是一个整数列表，包含三个元素：1、2 和 3。
更多详情请参见列表类型一节。

### 范围

范围表达式让你能够轻松创建两个值之间的整数列表。
语法为 `[e1..e2]`，其中 `e1` 和 `e2` 是常量表达式，会转换为 32 位整数（如果原本不是，则会调整为 32 位）。

假设 `e1` 的求值结果为 $n_1$，`e2` 的求值结果为 $n_2$。范围表达式生成一个从 $n_1$ 到 $n_2$ 的数字列表，每次递增或递减 1。列表的方向与端点的顺序一致：

- 如果 $n_1 < n_2$，列表从 $n_1$ 递增到 $n_2 - 1$。
- 如果 $n_1 > n_2$，列表从 $n_1 - 1$ 递减到 $n_2$。

例如：

- `[0..5]` 生成 `[0, 1, 2, 3, 4]`
- `[5..0]` 生成 `[4, 3, 2, 1, 0]`

### 列表访问

列表访问允许你通过索引获取列表中的元素。
语法为 `list[index]`，其中 `list` 是列表表达式，`index` 是求值结果为整数的常量表达式。
例如，

- `[1, 2, 3][0]` 的求值结果为 `1`，即列表的第一个元素。
- `[0, [1], AND, [AND, [OR], XOR]][3][1][0]` 通过逐层访问列表，求值结果为 `OR`。

### 拼接

列表拼接允许你将多个列表合并为一个列表。
语法为 `list1 ++ list2`，其中 `list1` 和 `list2` 都是列表表达式。
例如，

- `[1, 2] ++ [3, 4]` 生成 `[1, 2, 3, 4]`。
- `[0, [1], AND] ++ [2, [3], OR]` 生成 `[0, [1], AND, 2, [3], OR]`。

### 列表推导式

列表推导式是一种通过指定模式和来源来创建列表的简洁方式。
语法为 `[expr | qualifier]`，其中 `expr` 是待求值的表达式，`qualifier` 是指定列表来源、筛选条件或绑定的限定项。
限定项有三种类型：

- 生成器：`x in list`，遍历给定列表中的每个元素 `x`。
- 绑定：   `let x = expr`，将一个值绑定到变量，以供表达式使用。
- 筛选器：    `when condition`，根据布尔条件筛选元素。

限定项按出现顺序生效，这意味着后面的限定项可以使用前面限定项中的绑定和筛选后的元素。
以下是一些示例：

- `[x | x in [1, 2, 3]]` 的求值结果为 `[1, 2, 3]`。
- `[x | x in [0..10], when x & 1 == 1]` 的求值结果为 `[1, 3, 5, 7, 9]`。
- `[a[k] | i in [0..3], let k = i ** 2]` 的求值结果为 `[a[0], a[1], a[4], a[9]]`。
- `[i + j | i in [0..3], j in [0..3]]` 的求值结果为 `[0, 1, 2,  1, 2, 3,  2, 3, 4,  3, 4, 5]`。

列表推导式非常有用。
例如，如果我们想检查元素 x 是否在列表中，可以使用以下表达式：
`[x | x in list, when x == target] != []`，如果 `x` 在 `list` 中，其求值结果为 `true`，否则为 `false`。

## 元常量

元常量是用于元表达式的常量。
这些常量包括布尔字面量和数值字面量（更多详情请参见元类型一节）。
元常量与电路表达式中的常量（参见电路常量一节）的区别在于，它们不会被解释为组件，而是被解释为可用于元编程计算的值。

## 算术表达式

NetX 中的算术表达式用于对整数值执行数学运算。
NetX 同时支持一元和二元算术运算符。

一元前缀运算符 `+` 和 `-` 可应用于整数，分别表示正值或负值。
请注意，NetX 中所有数字都是无符号的，因此一元负号运算符 `-` 实际上是按二进制补码计算的。

支持的二元中缀运算符包括：

- `+` 用于加法
- `-` 用于减法
- `*` 用于乘法
- `/` 用于除法
- `%` 用于取模（求余）
- `**` 用于幂运算

这些运算符只能用于元表达式。运算符的优先级和结合性在运算符优先级与结合性一节中介绍。

## 逻辑表达式

NetX 中的逻辑表达式用于对布尔值执行布尔运算。
支持的逻辑运算符包括：

- `and` 用于逻辑合取（与）
- `or` 用于逻辑析取（或）
- `not` 用于逻辑否定（非）

逻辑表达式采用短路求值策略，即一旦结果确定，就停止求值。例如，在表达式 `a and b` 中，如果 `a` 为 `false`，则不会对 `b` 求值，因为整体结果已经确定为 `false`。

这些运算符只能用于元表达式。运算符的优先级和结合性在运算符优先级与结合性一节中介绍。

## 位运算表达式

NetX 中的位运算表达式用于对整数值执行按位运算。
支持的按位运算符包括：

- `~` 用于按位非（一元）
- `|` 用于按位或（二元）
- `&` 用于按位与（二元）
- `^` 用于按位异或（二元）
- `~^` 和 `^~` 用于按位同或（二元）

这些运算符只能用于元表达式。运算符的优先级和结合性在运算符优先级与结合性一节中介绍。

## 比较表达式

NetX 中的比较表达式用于比较两个值并返回布尔结果。
虽然这些运算符支持多种类型，但两个操作数必须具有相同的类型。
对于整数操作数，它们的位宽也必须匹配。

二元中缀相等性运算符为 `==`（相等）和 `!=`（不等）。
它们支持整数、布尔值和列表值。
如果两个列表长度相同，且所有对应元素都相等，则认为这两个列表相等。

二元中缀关系运算符包括：

- `<`  小于（有符号）
- `<=`  小于或等于（有符号）
- `>`  大于（有符号）
- `>=`  大于或等于（有符号）
- `<*`  小于（无符号）
- `>*`  大于（无符号）
- `<=*` 小于或等于（无符号）
- `>=*` 大于或等于（无符号）

这些运算符仅适用于整数值，并按数值大小进行比较。
`*` 后缀表示有符号比较：尽管 NetX 中的整数默认是无符号的，但这些运算符会将其二进制表示解释为有符号整数。

比较运算符只能用于元表达式。运算符的优先级和结合性在运算符优先级与结合性一节中介绍。

## 移位表达式

NetX 中的移位表达式用于对整数值执行位移运算。
支持的移位运算符包括：

- `<<` 用于逻辑左移
- `<<<` 用于算术左移
- `>>` 用于逻辑右移，补零
- `>>>` 用于算术右移，填充最高有效位

这些运算符只能用于元表达式。运算符的优先级和结合性在运算符优先级与结合性一节中介绍。

## 括号表达式

NetX 中的括号表达式用于对表达式进行分组并控制求值顺序。
支持的括号运算符包括：

- `(` 和 `)` 用于对表达式进行分组
- `[` 和 `]` 用于索引导线、数组和列表
- `{` 和 `}` 用于命名连接（参见组合子表达式一节）和语法分隔（参见组件作用域一节）

这些运算符既可用于电路表达式，也可用于元表达式。运算符的优先级和结合性在运算符优先级与结合性一节中介绍。

## 条件表达式

NetX 中的条件表达式允许你根据布尔条件在两个表达式之间进行选择。
语法为 `if condition then expr1 else expr2`，其中 `condition` 是布尔表达式，`expr1` 和 `expr2` 是类型相同的表达式。
如果 `condition` 的求值结果为 `true`，则结果为 `expr1`；否则，结果为 `expr2`。
条件表达式只能用于元表达式，且两个分支的类型必须匹配。

## 绑定表达式

NetX 中的绑定表达式允许你将一个值绑定到变量，以供后续表达式使用。
语法为 `let x = e1 in e2`，其中 `x` 是变量名，`e1` 是其值将被绑定到 `x` 的表达式，`e2` 是可以使用 `x` 的表达式。
它是基本 let 绑定一节中介绍的基本 let 绑定语句在表达式层面的等价形式。

## 运算符优先级与结合性

NetX 中的二元运算符均为左结合，但幂运算符 `**` 为右结合。
NetX 中的一元运算符如果是前缀运算符（例如 `+`、`-`、`~`、`not` 和前缀 `#`），则为右结合；如果是后缀运算符（例如后缀 `#`），则为左结合。

运算符的优先级从高到低及其结合性如下：

| 运算符 | 结合性 | 用法 |
| --- | --- | --- |
| `[]`、`.` | — | `expr[index]`、`expr.field` |
| `#` | 右结合（前缀）、左结合（后缀） | `#expr`、`expr#` |
| `+`、`-`、`~`、`not` | 右结合 | `+expr`、`-expr`、`~expr`、`not expr` |
| `**` | 右结合 | `expr ** expr` |
| `*`、`/`、`%` | 左结合 | `expr * expr`、`expr / expr`、`expr % expr` |
| `<<`、`<<<`、`>>`、`>>>` | 左结合 | `expr << expr`、`expr <<< expr`、`expr >> expr`、`expr >>> expr` |
| `<`、`<=`、`>`、`>=`、`<*`、`>*`、`<=*`、`>=*` | 左结合 | 关系比较 |
| `==`、`!=` | 左结合 | 相等性比较 |
| `&` | 左结合 | `expr & expr` |
| `^~`、`~^`、`^` | 左结合 | 同或与异或 |
| `\|` | 左结合 | `expr \| expr` |
| `and` | 左结合 | `expr and expr` |
| `or` | 左结合 | `expr or expr` |
| `++` | 左结合 | `expr ++ expr` |
| `<>` | 左结合 | `expr <> expr` |
| `\|\|` | 左结合 | `expr \|\| expr` |
| `if`、`then`、`else` | — | `if expr then expr else expr` |
| `()` | — | `(expr)` |

## 语法定义

这里定义 NetX 语言中表达式的语法。

```antlr
expression
  : symbol                                                          # SymbolExpr
  | STRING                                                          # StringExpr
  | number                                                          # NumberExpr
  | '[' list ']'                                                    # ListExpr
  | expression (selector)+                                          # AccessExpr
  | expression '.' ID                                               # FieldExpr
  | <assoc=right> prev='#' expression                               # UnaryExpr
  | <assoc=left> expression post='#'                                # UnaryExpr
  | <assoc=right> op=('+' | '-' | '~' | 'not') expression           # UnaryExpr
  | <assoc=right> lhs=expression op='**' rhs=expression             # BinaryExpr
  | lhs=expression op=('*' | '/' | '%') rhs=expression              # BinaryExpr
  | lhs=expression op=('+' | '-') rhs=expression                    # BinaryExpr
  | lhs=expression op=('>>'| '<<' | '>>>' | '<<<') rhs=expression   # BinaryExpr
  | lhs=expression op=('<' | '<=' | '>'  | '>=') rhs=expression     # BinaryExpr
  | lhs=expression op=('<*' | '<=*' | '>*'  | '>=*') rhs=expression # BinaryExpr
  | lhs=expression op=('==' | '!=') rhs=expression                  # BinaryExpr
  | lhs=expression op='&' rhs=expression                            # BinaryExpr
  | lhs=expression op=('^~' | '~^' | '^') rhs=expression            # BinaryExpr
  | lhs=expression op='|' rhs=expression                            # BinaryExpr
  | lhs=expression op='and' rhs=expression                          # BinaryExpr
  | lhs=expression op='or' rhs=expression                           # BinaryExpr
  | lhs=expression op='++' rhs=expression                           # BinaryExpr
  | lhs=expression op='<>' rhs=expression                           # BinaryExpr
  | lhs=expression op='||' rhs=expression                           # BinaryExpr
  | '{' port_assign (',' port_assign)* '}'                          # PortExpr
  | 'if' cond=expression
    'then' thenBranch=expression
    'else' elseBranch=expression                                    # ConditionalExpr
  | '(' expression ')'                                              # ParenExpr
  ;

port_assign
    : 'default' ':' rhs=expression
    | lhs=expression ':' rhs=expression
    ;
```
