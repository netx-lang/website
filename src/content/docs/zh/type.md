# 类型

为了帮助在开发过程的早期发现潜在问题，NetX 采用静态强类型系统，这意味着每个表达式的类型都在编译时确定，类型错误会在仿真或其他处理之前被发现。

NetX 中的类型可以分为两大类：电路类型和元类型。
电路类型描述硬件组件的输入和输出信号；元类型则规定元编程期间可以执行的有效操作。

## 电路类型

电路组件的类型描述该组件的输入和输出信号，记作 $\langle \mathit{sig} \cdots \mathit{sig}\rangle \to \langle \mathit{sig} \cdots \mathit{sig}\rangle$，从输入信号类型的有序列表指向输出信号类型的有序列表。
这里，该组件的每个输入和输出端口都有特定的信号类型，记作 sig。

### 信号类型

信号类型（记作 sig）是电路类型的基本构建单元，表示电路中的数据流。
信号类型分为基本信号类型和复合信号类型：

#### 基本信号类型

基本信号类型规定导线所承载的信号。
它可以是 n 位宽的数据类型，记作 bit(n)；也可以是时钟信号类型，记作 clock。
时钟信号是一种位宽为 1 位的特殊信号，会定期在 0 和 1 之间翻转。
值得注意的是，时钟类型 clock 与 1 位数据类型 bit(1) 不匹配时，编译期间应仅发出警告，因为它们在某些场景下可以互换。

此外，枚举实际上也是基本信号类型。例如，以下枚举定义

```netx
enum COLOR {
  RED = 2'b00, GREEN = 2'b01, BLUE = 2'b10
}
```

可以用在 `wire color of COLOR;` 中，表示一条承载 `COLOR` 信号的导线，该信号最终是一个 2 位宽的数据信号。
换句话说，这等价于在 NetX 代码中定义 `wire color of bit(2);`---枚举只是特定值在编译时的别名。

请注意，NetX 中的导线并不直接具有信号类型，因为导线是一种将输入信号直接传递到输出的特殊组件。
从这个意义上说，声明 `wire a of bit(1);` 指定了一条承载 1 位数据信号的导线，实际上是指定了一条类型为 $\langle \mathrm{bit}(1)\rangle \to \langle \mathrm{bit}(1)\rangle$ 的导线。

#### 复合信号类型

复合信号类型通过组合多个信号类型来形成更复杂的数据结构，具体包括数组和线束：

- 数组类型表示一组类型相同的信号，记作 sig[n]，其中 n 是在编译时确定的数值。
  例如，声明 `wire a[4] of bit(32);` 指定了一个类型为 bit(32)[4] 的数组，表示它包含 4 个元素，即 `a[0]`、`a[1]`、`a[2]`、`a[3]`，每个元素的类型都是 `bit(32)`。
  在编译期间，编译器应将承载数组类型信号的导线展平。
  也就是说，如果数组 `a` 单独出现在表达式中，就应将其转换为基本导线列表 `[a[0], a[1], a[2], a[3]]`，每条导线的类型都是 `bit(32)`。
  值得注意的是，虽然 `a[0]` 在 NetX 中不是有效的标识符，但为了便于这种处理，它在后端表示 NXON 中是有效的。
- 线束类型表示一组类型不同的信号，每个信号都有一个字段名。
  这些类型由接口定义，接口是一种将多条导线组合在一起的特殊组件。
  例如，以下定义：
  
```netx
interface PACKAGE : [valid, load] {
  wire valid of bit(1);
  wire load of bit(32);
}
```

  指定了一个名为 `PACKAGE` 的特殊组件，它有两个输入信号 `valid` 和 `load`，类型分别为 `bit(1)` 和 `bit(32)`。
  该组件的输出信号具有线束类型，记作
  The bundle type is $\tau ::= \{\, \mathrm{valid} : \mathrm{bit}(1),\ \mathrm{load} : \mathrm{bit}(32) \,\}_{\mathrm{PACKAGE}}$
  那么，`PACKAGE` 组件的类型应为 $\langle \mathrm{bit}(1), \mathrm{bit}(32)\rangle \to \langle \tau\rangle$，其作用类似于构造函数。
  此外，我们可以定义 `bundle pack of PACKAGE;`，其类型为 $\langle \tau\rangle \to \langle \tau\rangle$，并通过字段名访问该线束内部的导线，其中 `pack.valid` 的类型为 $\langle \mathrm{bit}(1)\rangle \to \langle \mathrm{bit}(1)\rangle$，`pack.load` 的类型为 $\langle \mathrm{bit}(32)\rangle \to \langle \mathrm{bit}(32)\rangle$。
  此外，在编译期间，编译器应将线束拆解为导线列表。
  也就是说，如果线束 `pack` 单独出现在表达式中，就应将其转换为基本导线列表 `[pack.valid, pack.load]`，其中两条导线的类型分别为 `bit(1)` 和 `bit(32)`。

值得注意的是，复合信号类型可以嵌套，这意味着我们可以有线束数组、由线束组成的线束，等等。
对这些嵌套类型进行展平或拆解时，应遵循嵌套顺序，即线束数组应先展平，再拆解。

### 组件类型

组件类型描述硬件组件的输入和输出信号。
它表示为 $\langle \mathit{sig} \cdots \mathit{sig}\rangle \to \langle \mathit{sig} \cdots \mathit{sig}\rangle$，其中左侧是输入信号类型的元组，右侧是输出信号类型的元组。

例如，寄存器是一种接收输入数据信号和时钟信号的组件，它在时钟信号的边沿（即时时钟信号翻转时）存储输入数据，并将存储的数据作为输出信号输出。
寄存器可以定义如下：

```netx
component REG : [data, clk] -> [out] {
  wire data, out of bit(32);
  wire clk of clock();
  /* ... */
}
```

该组件的类型为 $\langle \mathrm{bit}(32), \mathrm{clock}\rangle \to \langle \mathrm{bit}(32)\rangle$。

除了上面所示寄存器这样的常见组件之外，NetX 还将实体（包括导线、常量、接口和线束）视为特殊的组件：

- 导线是接收输入信号并将其直接传递到输出的组件。
  承载 1 位数据信号的导线可以声明为 `wire data of bit(1);`，其类型为 $\langle \mathrm{bit}(1)\rangle \to \langle \mathrm{bit}(1)\rangle$，正如我们在信号类型一节中已经讨论过的那样。
- 常量是没有输入信号并输出固定值的组件。
  例如，字面量 `4'b1010` 是类型为 $\langle \rangle \to \langle \mathrm{bit}(4)\rangle$ 的常量，而浮点字面量 `3.14` 是类型为 $\langle \rangle \to \langle \mathrm{bit}(32)\rangle$ 的常量。
  值得注意的是，常量有时可能具有元类型而非电路类型，这取决于它们出现的上下文（即表达式的种类）。
- 接口和线束是与我们在信号类型一节中讨论过的线束类型相关的特殊组件：
  线束是一种直通组件，接收线束类型的输入并原样输出；接口则接收多个输入信号，输出一个线束类型的信号，充当线束构造函数。

### 组件类型上的运算符

并行组合运算符 `||`、顺序组合运算符 `<>` 和端口修饰符 `#` 是仅有的三个可以对组件类型的操作数进行操作的运算符。
这些运算符的结合性和优先级将在运算符优先级与结合性一节中讨论。

#### 并行组合运算符

并行组合运算符 `||` 用于以并行方式组合两个组件，使这些组件能够独立且同时运行。

例如，将两个 2 输入 1 输出的组件并行组合，就能得到一个 4 输入 2 输出的组件。给定一个类型为 $\langle \mathrm{bit}(1), \mathrm{bit}(1)\rangle \to \langle \mathrm{bit}(1)\rangle$ 的组件 `AND`，它对两个 1 位输入执行逻辑与运算，两个这样的门的并行组合可以表示为 `AND || AND`，得到的组件类型为 $\langle \mathrm{bit}(1), \mathrm{bit}(1), \mathrm{bit}(1), \mathrm{bit}(1)\rangle \to \langle \mathrm{bit}(1), \mathrm{bit}(1)\rangle$。

#### 顺序组合运算符

顺序组合运算符 `<>` 用于以顺序方式组合两个组件，将第二个组件的输出作为第一个组件的输入，类似于函数复合。
这要求第二个组件的输出类型与第一个组件的输入类型匹配。

例如，将一个 4 输入 2 输出的组件与一个 2 输入 1 输出的组件顺序组合，就能创建一个 4 输入 1 输出的组件。
给定我们刚刚讨论过的组件 `(AND || AND)`，其类型为 $\langle \mathrm{bit}(1), \mathrm{bit}(1), \mathrm{bit}(1), \mathrm{bit}(1)\rangle \to \langle \mathrm{bit}(1), \mathrm{bit}(1)\rangle$，我们可以将它与一个 2 输入 1 输出的组件组合，例如另一个类型为 $\langle \mathrm{bit}(1), \mathrm{bit}(1)\rangle \to \langle \mathrm{bit}(1)\rangle$ 的 `AND` 门。
这可以表示为 `AND <> (AND || AND)`，得到的组件类型为 $\langle \mathrm{bit}(1), \mathrm{bit}(1), \mathrm{bit}(1), \mathrm{bit}(1)\rangle \to \langle \mathrm{bit}(1)\rangle$---这是一个对四个输入执行逻辑与运算的 4 输入 1 输出组件。

#### 端口修饰符

端口修饰符 `#` 用于忽略组件的输入或输出端口。
通过在组件表达式的前面或后面添加 `#`，我们可以分别得到一个忽略输入或输出端口的新组件。在某些场景下，当我们需要调整组件类型以便于元编程时，这会很有用。更多详情请参阅修饰符表达式一节。

例如，给定一个类型为 $\langle \mathrm{bit}(1), \mathrm{bit}(1)\rangle \to \langle \mathrm{bit}(1)\rangle$ 的组件 `AND`，表达式 `#AND` 得到的组件类型为 $\langle \mathrm{bit}(1), \mathrm{bit}(1)\rangle \to \langle \rangle$，而表达式 `AND#` 得到的组件类型为 $\langle \rangle \to \langle \mathrm{bit}(1)\rangle$。

## 元类型

元类型用于规定元编程期间可以执行的有效操作，元编程是对硬件设计中的电路结构模式进行抽象的过程（进一步讨论请参阅元编程一节）。
目前，NetX 支持布尔类型和整数类型等基本元类型，也支持由这些基本类型以及我们在电路类型一节中讨论过的电路类型组合而成的类型。

### 布尔类型

- 布尔字面量只有 `true` 和 `false` 两个，分别表示布尔类型的两个可能值。
  从其他类型创建布尔值的唯一方法是使用比较运算符，这将在整数类型一节中讨论。
- 在某些程序结构中，例如 `if then else` 表达式和 `when` 筛选限定符，整数值可以隐式转换为布尔值：零被视为 `false`，任何非零值都被视为 `true`。
- 逻辑运算符 `and`、`or` 和 `not`，以及比较运算符 `==` 和 `!=`，是仅有的可以应用于布尔值的运算符。
  这些运算符的结合性和优先级将在运算符优先级与结合性一节中讨论。
  以下是一些示例：
  - `true and false` 的求值结果为 `false`。
  - `not true` 的求值结果为 `false`。
  - `(true == false) or true` 的求值结果为 `true`。
  - `false and (true != false)` 的求值结果为 `false`。
- 布尔类型的表达式可以用于元编程控制结构。
  这些结构包括
  - 条件表达式 `if b1 then e1 else e2` 要求 `b1` 具有布尔类型。
  - 列表推导式中的筛选限定符 `when b1` 要求 `b1` 具有布尔类型。
  关于列表推导式的更多详情，请参阅列表推导式一节。
  例如，表达式
  
```netx
[x | x in [0, 1, 2, 3, 4, 5], when x % 2 == 1]
```

  的求值结果为 `[1, 3, 5]`。

### 整数类型

#### 整数字面量

通常，NetX 中的整数字面量表示为以下形式

```netx
<width>'<radix><digits>
```

其中，`width` 是位数，`radix` 是数制的基数（例如，`b` 表示二进制，`o` 表示八进制，`d` 表示十进制，`h` 表示十六进制），`digits` 是该数在相应进制下的数字序列。
例如，`4'b1010` 表示位宽为 4 位的二进制数 `1010`，它等价于八进制数 `4'o12`、十进制数 `4'd10` 或十六进制数 `4'hA`。
对于未指定位宽和基数的字面量，编译器应将其视为 32 位十进制数。

值得注意的是，给定的数字序列可能与指定的位宽不匹配，在这种情况下，编译器会在字面量前补零或将其截断，以适应指定的位宽。
例如：

- `8'b11010` 等价于 `8'b00011010`，因为应在 5 位二进制数 `11010` 前补零以适应 8 位宽度，得到 `00011010`。
- `7'hFF` 等价于 `7'h7F`，因为应将 8 位十六进制数 `FF` 截断以适应 7 位宽度，得到 `7F`。
- 如果一个未指定位宽和基数的数按 32 位十进制数处理，而其表示的值超出了 32 位无符号整数的范围，编译器应将该数截断以适应 32 位宽度。

以下整数字面量均有效：

```netx
4'b1010,          8'hFF,            12'o17,           32'd42,
4'B10,            8'Hff,            12'O17,           32'D42,
0,                12109432443123,   1_000_000_000,    540'd7_145_234_892
```

#### 整数运算符

以下运算符可以应用于整数值：

- 算术运算符。
  二元算术运算符包括 `+`、`-`、`*`、`/`、`%` 和 `**`，分别执行加法、减法、乘法、除法、取模和幂运算。
  这些运算符生成的整数值与两个操作数的位宽相同。
  一元算术运算符是 `+` 和 `-`，分别执行恒等和取负运算。
  由于整数均为无符号数，取负（以及减法）通过该值的二进制补码来计算。
  一元运算符生成的整数值与其操作数的位宽相同。
  请注意，上面列出的一些运算符可能产生超出有界整数范围的结果，在这种情况下，结果会被截断以适应指定的位宽。
  例如，表达式 `4'd5 * 4'd5` 的求值结果为 `4'd9`，因为结果 `25`（`11001`）超出了 4 位无符号整数的范围，即 `0-15`，因此被截断为 `9`（`1001`）。
- 按位运算符。
  二元按位运算符包括 `&`、`|`、`^` 和 `~^`，分别执行按位与、或、异或和同或运算。
  同或运算符 `~^` 也可以写作 `^~`，两者可以互换。
  这些运算符生成的整数值与两个操作数的位宽相同。
  一元按位运算符是 `~`，它执行按位取反运算，生成与其操作数位宽相同的整数值。
- 移位运算符。
  移位运算符包括 `>>`、`<<`、`>>>` 和 `<<<`，分别执行右移、左移、算术右移和算术左移运算。
  将一个值向左移动时，`<<` 和 `<<<` 都会用零填充空出的位。
  将一个值向右移动时，`>>` 会用零填充空出的位，而 `>>>` 会用该值的符号位（最高有效位）填充空出的位。
  这些运算符要求两个操作数具有相同的类型，并生成与第一个操作数位宽相同的整数值。
- 比较运算符。
  比较运算符包括 `==`、`!=`、`<`、`<=`、`>`、`>=`、`<*`、`<=*`、`>*` 和 `>=*`。
  后缀 `*` 表示无符号比较，即操作数被视为无符号整数，而不是有符号整数。
  这些运算符生成布尔值作为结果，并且具有左结合性。

这些运算符的结合性和优先级将在运算符优先级与结合性一节中讨论。

### 浮点类型

#### 浮点字面量

通常，NetX 中的浮点字面量表示为以下形式

```netx
<width>'[fF]<digits>
```

其中，`width` 是位数，`digits` 是该数在相应进制下的数字序列。
支持的位宽为 16、32 和 64 位，分别对应 IEEE 754 的半精度、单精度和双精度格式。
例如，`32'F3.14` 表示单精度浮点数 3.14。
对于未指定位宽和基数的字面量，编译器应将其视为 32 位单精度浮点数。

#### 浮点运算符

以下运算符可以应用于浮点值：

- 算术运算符。
  二元算术运算符包括 `+`、`-`、`*`、`/` 和 `**`，分别执行加法、减法、乘法、除法和幂运算。
  这些运算符生成的浮点值的位宽取两个操作数位宽的最大值。
  一元算术运算符是 `+` 和 `-`，分别执行恒等和取负运算。
- 比较运算符。
  比较运算符包括 `==`、`!=`、`<`、`<=`、`>`、`>=`。
  这些运算符生成布尔值作为结果，并且具有左结合性。

具体而言，在浮点值和整数值之间执行运算时，编译器应先将整数值隐式转换为与浮点操作数位宽相同的浮点值，再执行运算。

这些运算符的结合性和优先级将在运算符优先级与结合性一节中讨论。

### 列表类型

NetX 支持使用列表表示一组实体，其中

- 列表字面量用方括号括起来，元素之间用逗号分隔。
  例如，`[1, 2, 3]` 是一个整数列表，包含三个元素 `1`、`2` 和 `3`。
- 包含连续整数的列表可以使用范围表示法指定。
  例如，`[1..5]` 等价于 `[1, 2, 3, 4]`；而 `[5..1]` 等价于 `[4, 3, 2, 1]`。
- 列表可以嵌套，并且不要求元素具有相同的类型。例如，`[false, 1]`、`[AND <> (AND || AND), 4'b1010, 32'd42]` 和 `[1, [2], [true, false]]` 都是有效的列表。
- 列表是有序集合，可以使用 `==` 和 `!=` 按顺序比较元素。
  列表相等的定义是：两个列表的元素数量相同，且每一对对应元素都相等。
  例如，`[1, 2, 3] == [1, 2, 3]` 的求值结果为 `true`，而 `[1, 2, 3] == [1, 2, 3, 4]` 的求值结果为 `false`。
- 列表中的元素可以通过索引访问，索引从 0 开始。
  例如，`[true, false][0]` 的求值结果为 `true`，而 `[1, [2]][1][0]` 的求值结果为 `2`。
- 列表可以使用列表连接运算符 `++` 进行连接，该运算符将右侧列表的元素追加到左侧列表。
  例如，`[1, 2] ++ [3, 4]` 的求值结果为 `[1, 2, 3, 4]`。
- 列表可以使用列表推导式构造。更多详情请参阅列表推导式一节。

### 函数类型

函数类型规定了 NetX 中哪些参数化宏是有效的，即只有具有有效函数类型的参数化宏才能用于元编程。
以下是 NetX 中函数类型的一些示例：

```netx
component AND_120 : [a, b] -> [out] {
  wire a, b, out of bit(120);
  /* ... */
}

component test {
  let fact(i) = if i == 0 then 1 else i * fact(i - 1);
  let tower(box) = box <> (box || box);
  
  wire a of bit(fact(5));
  a <> tower(AND_120);
}
```

这里，`fact` 是一个形式为 $\lambda i.\ \cdots$ 的匿名函数，当它用于表达式 `fact(5)` 时便会被应用，此时其类型被确定为 $\mathrm{bit}(32) \to \mathrm{bit}(32)$，表示它接收一个整数作为输入，并返回一个整数作为输出。
同样，`tower` 的类型被确定为 $(\langle \mathrm{bit}(120), \mathrm{bit}(120) \rangle \to \langle \mathrm{bit}(120) \rangle) \to (\langle \mathrm{bit}(120), \mathrm{bit}(120), \mathrm{bit}(120), \mathrm{bit}(120) \rangle \to \langle \mathrm{bit}(120) \rangle)$，表示它接收一个 2 输入 1 输出的组件作为输入，并返回一个 4 输入 1 输出的组件作为输出。

关于参数化宏和函数类型的更多详情，请参阅元编程一节。
